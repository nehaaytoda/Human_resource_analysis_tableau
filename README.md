# Human Resource Dashboard

## Overview

The [**Human Resource Dashboard**](https://public.tableau.com/shared/C57Y285HS?:display_count=n&:origin=viz_share_link) is an interactive analytics solution designed to explore and analyze HR data efficiently. It provides both **high-level summaries** for strategic insights and **detailed employee-level views** for deeper analysis, supporting informed decision-making by HR teams and management.

The dataset used in this project was **synthetically generated** using **ChatGPT** and the **Faker library**, ensuring realistic yet non-sensitive employee data.


### 📈 HR Summary Dashboard

The [**HR Summary**](https://public.tableau.com/shared/C57Y285HS?:display_count=n&:origin=viz_share_link) offers a consolidated overview of the organization’s workforce and is divided into three key sections:

* **Overview**
  High-level workforce metrics and overall HR indicators

* **Demographics**
  Analysis of employee distribution by attributes such as gender, age, education, and department

* **Income Analysis**
  Salary trends and compensation comparisons across roles, departments, and demographics<br/>

### 📋 Employee Records Dashboard

The [**Employee Records View**](https://public.tableau.com/shared/YXZMGH3D3?:display_count=n&:origin=viz_share_link) provides a detailed, tabular listing of all employees, enabling granular analysis.

**Key Features:**

* Displays employee information including:

  * Name
  * Department
  * Job Position
  * Gender
  * Age
  * Education Level
  * Salary

* Interactive filtering on all available fields for easy exploration and analysis
